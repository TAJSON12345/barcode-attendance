# Barcode Attendance Management System

## Overview

The Barcode Attendance Management System is a web-based application developed to automate student attendance management using barcode technology.

The system eliminates manual attendance registers by allowing staff and lecturers to scan student barcodes and automatically record attendance.

---

## Features

- User Authentication
- Role-Based Access Control
- Student Management
- Course Management
- Barcode Generation
- Barcode Attendance Scanning
- Attendance Reports
- Dashboard Statistics
- PDF Attendance Reports

---

- Manage Courses

- View Attendance Reports
